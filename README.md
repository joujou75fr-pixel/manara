# منارة — تطبيق شاشة المسجد (Android و iOS)

تطبيق يعرض مواقيت الصلاة ويدير تلقائيًا مراحل الأذان والإقامة والصلاة والأذكار.
الواجهة في `www/` والتطبيقان الأصليان في `android/` و `ios/` (Capacitor 7).

## ما يضيفه التطبيق مقارنة بنسخة المتصفح
- يعمل دون إنترنت بالكامل (الخطوط مضمّنة في `www/fonts`).
- الشاشة تبقى مضاءة طوال فتح التطبيق، وشريط الحالة مخفي.
- إشعار عند كل أذان للأيام السبعة القادمة (يُفعَّل من الإعدادات ← تنبيهات الهاتف)، ويتجدد عند كل فتح للتطبيق.
- تنبيه صوتي عند دخول الوقت: «حان الآن موعد أذان صلاة …» باسم الصلاة (والجمعة يوم الجمعة)، مع شاشة إعلان كاملة لمدة دقيقة.

## الطريقة الأسهل: بناء APK عبر GitHub (دون تثبيت أي شيء)
1. أنشئ مستودعًا جديدًا على GitHub وارفع إليه محتوى هذا المجلد.
2. افتح تبويب **Actions** ← **Build Manara** ← **Run workflow**.
3. بعد نحو 5 دقائق حمّل `manara-android-apk` من صفحة التشغيل، وثبّت `app-debug.apk` على الهاتف أو جهاز التلفاز (Android TV Box).

## البناء على حاسوبك
المتطلبات: Node.js 20+، و Android Studio لنسخة Android، و Mac مع Xcode 16+ لنسخة iOS.

```bash
npm install
npx cap sync
npx cap open android   # ثم Run أو Build > Build APK(s)
npx cap open ios       # على Mac فقط، ثم اختر فريق التوقيع (Signing) وشغّل
```

بعد أي تعديل على ملفات `www/` نفّذ `npx cap sync`.

## ملاحظات
- **iOS**: النشر على iPhone أو App Store يتطلب حساب Apple Developer (99$ سنويًا). يمكن التجربة على جهازك الشخصي بحساب Apple مجاني لمدة 7 أيام.
- **Google Play**: يلزم توقيع نسخة Release (`Build > Generate Signed Bundle`) وحساب مطوّر (25$ مرة واحدة).
- **دقة الإشعارات على Android 12+**: إن تأخرت الإشعارات، فعّل «المنبهات والتذكيرات» للتطبيق من إعدادات الهاتف.
- **الأيقونات**: مصدرها في `assets/`. لتغييرها استبدل الصور ثم نفّذ `npm run assets`.
- **المواقيت**: الفجر 18° والعشاء 17°. طابِقها مع رزنامة وزارة الشؤون الدينية وصحّح الفارق من الإعدادات.

## الأذان الكامل
من الإعدادات ← صوت الأذان اختر «الأذان كاملًا» ثم ملف الأذان (MP3 أو M4A)، وملفًا آخر اختياريًا لأذان الفجر. يُحفظ الملف على الجهاز ويُشغَّل عند كل صلاة.

لإدراج أذان ثابت داخل التطبيق نفسه دون اختياره من الإعدادات، ضع الملفين باسم `www/sounds/adhan.m4a` و `www/sounds/adhan_fajr.m4a` ثم نفّذ `npx cap sync`. استعمل تسجيلًا تملك حق استعماله (أذان مؤذن مسجدك مثلًا).

## ملفات الصوت
التنبيه الصوتي مولَّد بصوت اصطناعي عربي. لاستبداله بصوت مسجَّل (المؤذن مثلًا) ضع ملفاتك بالأسماء نفسها في:
- `www/sounds/adhan_<الصلاة>.m4a` (التشغيل داخل التطبيق)
- `android/app/src/main/res/raw/adhan_<الصلاة>.wav` و `ios/App/App/adhan_<الصلاة>.wav` (صوت الإشعار، أقل من 30 ثانية)

الأسماء: fajr, dhuhr, asr, maghrib, isha, jumua. ثم نفّذ `npx cap sync`.
على Android تُحفظ أصوات الإشعارات في «قنوات» لا تتغير بعد إنشائها: عند تبديل الملفات غيّر اللاحقة `_v1` إلى `_v2` في `www/native.js`.
